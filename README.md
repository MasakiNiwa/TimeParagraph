# TimeParagraph

パラグラフ単位で話す時間と内容を考えるエディタ

会議・ミーティング・講義などで話す内容をパラグラフごとに組み立てながら、各パラグラフを話すのにかかる時間を推定し、全体の所要時間を計算します。

**公開ページ:** https://masakiniwa.github.io/TimeParagraph/

## 主な機能

- **パラグラフエディタ**:段落ごとに書き、並べ替え・分割・結合。段落ごとの話す時間・開始時刻と合計時間を表示
- **構成**:見出しと段落をセクションとしてまとめて移動・たたむ、内容のタイプ(導入・結論・具体例など)の表示、構成テンプレート(組み込み + 自分で保存)
- **時間の推定**:文字数 / 拍数(簡易)/ 拍数(形態素解析、Web Worker で実行)から選択
- **目標時間と時間配分**:残り時間・超過時間と、セクションごとの配分バー
- **練習**:リハーサル計測(実測から自分の話す速さを補正)、読み上げ、発表モード
- **分析**:時間の内訳のドリルダウン、段落のバランス、長い文、リハーサルの比較。分析ツールは登録制で追加可能
- **AI アシスタント(任意)**:Gemini / OpenAI / Claude / OpenRouter(ログインでキー取得・多数のモデルから検索して選択)。アプリの状態を構造化データで渡し、計算はアプリの機能をツールとして使用。編集案はユーザーが確認して適用。API キーはパスフレーズで暗号化して保存することもできます
- **入出力**:Markdown・時間つきテキスト・JSON の書き出し/取り込み
- **PWA**:ホーム画面に追加、オフライン対応

## 開発

Node.js 22 以上が必要です。

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト
npm run lint       # Lint
npm run typecheck  # 型チェック
npm run build      # 本番ビルド(dist/)
```

`main` ブランチへのマージで GitHub Actions が GitHub Pages へ自動デプロイします。
