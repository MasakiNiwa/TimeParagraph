## 確認の限界と次の確認候補

- Gemini / OpenAI / Claude への実際の有料 API 呼出しは行っていない。会話の競合・編集案の検証はモックとアプリ側の処理で確認した。実際の認証・モデル対応・通信制約は各サービスの利用環境で確認が必要。
- Pixel 実機・Safari・実際の音声合成エンジンでの発声、OS の画面ロック、PWA のインストール案内は未検証。読み上げの時間制御は模擬音声エンジンで検証した。
- 原稿変更後の計測や別タブとの競合では、自動で内容を統合しない。警告に従って再開始・バックアップ・再読込する方式。
- ブラウザの強制終了・端末の電源断まで保存を保証するものではない。保存済みの表示と JSON バックアップを利用する。
- ビルド時に、依存パッケージのコメント注釈と一部チャンクの 500kB 超過に関する警告が残る。次の性能改善では AI・分析の読込量と長大原稿の描画を実測するとよい。
